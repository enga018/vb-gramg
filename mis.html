MIS

Import your Excel workbook and apply the same data-cleaning, Unique ID, and MAIN comparison rules as the VBA macro.

Import and process Excel

Select the raw workbook downloaded/exported from the chosen system. Processing runs in this browser; the file is not uploaded to a server.

Uses the VBA row layout: data starts at Excel row 17, and the last two rows are excluded. It reads columns 9, 2, 4 and 11.

If supplied, the MIS output is compared against column G of the MAIN sheet. New records are highlighted and can be exported as an updated MAIN workbook.

Choose the raw Excel file to begin.

The original files are never modified. Downloads create new files. This matches the VBA data processing and comparison steps; it does not automatically write back to your local MAIN.xlsx.
